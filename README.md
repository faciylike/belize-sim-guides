## 搞定设置：让网络跑起来

　　买到卡，插进手机，事情只完成了一半。**APN设置**是关键一步，否则可能上不了网。通常插卡后运营商会自动下发配置信息，但万一没有呢？

*   Digi的APN通常是 `digimobile.bz`
*   Smart的是 `smart.bz`

　　手动检查一下手机网络设置里的APN选项，确保这里填对了。这个小小设置拦住了不少粗心的旅行者，你说是不是？
